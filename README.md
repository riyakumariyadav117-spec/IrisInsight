IrisInsight – Iris Flower Classification

Project Overview

This project is part of my CodeAlpha Data Science Internship.

The objective is to build a Machine Learning model that predicts Iris flower species based on flower measurements.

Dataset

The Iris dataset contains three flower species:

- Iris Setosa
- Iris Versicolor
- Iris Virginica

Features used:

- Sepal Length
- Sepal Width
- Petal Length
- Petal Width

Technologies Used

- Python
- Pandas
- Matplotlib
- Seaborn
- Scikit-learn
- Google Colab

Project Steps

1. Dataset loading
2. Data exploration
3. Data visualization
4. Train-test splitting
5. Logistic Regression model training
6. Model prediction
7. Accuracy evaluation

Model Performance

Algorithm: Logistic Regression

Test Accuracy: 100%
