# CodeAlpha Task 2 – Unemployment Analysis with Python

This project analyzes unemployment trends in India using Python.

## Tools and Libraries
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab

## Project Overview
The project explores unemployment data from May 2019 to June 2020, covering 28 regions of India.

## Key Analysis
- Data cleaning and preprocessing
- State-wise unemployment analysis
- Rural vs Urban comparison
- Monthly unemployment trends
- Before and during COVID-19 comparison
- Data visualization

## Dataset
Unemployment in India dataset.

## Notebook
The complete analysis and visualizations are available in the Jupyter Notebook in this folder.
